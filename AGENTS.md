# AGENTS.md

## Назначение

OpenAlice — приватный голосовой мост между навыком Яндекс Алисы и домашним
OpenClaw Gateway. FastAPI принимает webhook Яндекс Диалогов, передаёт обычные
реплики агенту через OpenResponses API и преобразует ответы в формат Алисы.

## Архитектура и порты

- Яндекс Диалоги → ngrok → `127.0.0.1:8765` (OpenAlice).
- Webhook: `POST /alice/webhook/{secret}`.
- Проверка приложения: `GET /health`.
- OpenAlice → `http://127.0.0.1:18789/v1/responses` (OpenClaw Gateway).
- SQLite хранит дедупликацию, поколения диалогов и отложенные ответы.

## Основные файлы

- `openalice/app.py` — FastAPI, команды, дедлайн и отложенные ответы.
- `openalice/openclaw_client.py` — клиент OpenClaw и повторы при 502/503/504.
- `openalice/commands.py` — распознавание служебных команд по шаблонам.
- `openalice/alice_models.py` — модели протокола Яндекс Диалогов.
- `openalice/store.py` — асинхронный интерфейс SQLite.
- `openalice/config.py` — настройки из `.env`.
- `openalice/text.py` — очистка и сокращение текста для озвучивания.
- `scripts/run-openalice.ps1` — запуск на Windows.
- `tests/` — тесты приложения, команд, хранилища и обработки текста.

## Ключевое поведение

- Алиса ждёт webhook около 4,5 секунды. OpenAlice ждёт быстрый ответ примерно
  3,8 секунды, затем сохраняет задачу и просит пользователя сказать «готово».
- Поле OpenResponses `user` задаёт стабильную сессию OpenClaw. Команда «новый
  диалог» увеличивает поколение и создаёт новую сессию.
- Повтор одного webhook возвращает закэшированный ответ и не вызывает агента
  второй раз.
- Служебные команды: помощь, получение результата, отмена, новый диалог, выход.
- Логи содержат этапы, длительность и сокращённые хеши идентификаторов, но не
  должны содержать реплики, токены или полные пользовательские ID.

## Локальный запуск

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e . --group dev
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m uvicorn openalice.app:create_app --factory --host 127.0.0.1 --port 8765
```

Туннель запускается отдельно:

```powershell
ngrok http 8765
```

## Проверка изменений

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Перед завершением работы запускайте весь набор тестов. При изменении команд,
дедлайна, повторов Gateway или формата ответа добавляйте соответствующий тест.

## Настройки и безопасность

- Все настройки перечислены в `.env.example`; реальные значения находятся в
  `.env` и никогда не должны попадать в Git или логи.
- `ALICE_WEBHOOK_SECRET` является частью публичного URL, но должен оставаться
  секретным и сравнивается через `hmac.compare_digest`.
- `OPENCLAW_GATEWAY_TOKEN` даёт операторский доступ. Не выводить его и не
  публиковать порт 18789 через ngrok.
- Не коммитить `.env`, SQLite-файлы, логи, временные каталоги и виртуальные
  окружения.
- Не заменять обработку отложенного результата долгим ожиданием webhook: это
  нарушит ограничение Яндекс Диалогов.

## Стиль изменений

- Поддерживать Python 3.13 и асинхронный путь обработки запросов.
- Сохранять OpenAlice тонким адаптером; сценарии, память и инструменты должны
  оставаться в OpenClaw.
- Пользовательские ответы писать по-русски, кратко и без Markdown, пригодными
  для озвучивания.
- Полная инструкция по установке, публикации навыка и автозапуску находится в
  `README.md`.
