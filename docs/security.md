# Безопасность

Храните реальные секреты в локальном .env, не добавляйте их в Git.
Gateway слушает локальный порт 18789; через ngrok публикуется только OpenAlice.

ALICE_WEBHOOK_SECRET проверяется constant-time сравнением. Allowlist ограничивает
аккаунты. Логи должны содержать только сокращённые хеши, этапы и длительность.

Ранее токен Gateway находился в отслеживаемом Bruno-запросе. Он удалён из текущей
версии, но сохранился в истории Git: оператору необходимо отозвать старый токен
и заполнить новое значение только в локальном окружении. Подтверждения ротации
в рамках этого change пока нет.

Не публикуйте .env, SQLite-базы, credential JSON, логи и отчёты с секретами.
