# Разработка

Требуется Python 3.13. Установите dev dependencies согласно [установке](setup.md).

Полный набор тестов:

```powershell
.\scripts\test.ps1
```

Полная проверка формата, lint, строгих типов, архитектуры и покрытия:

```powershell
.\scripts\check.ps1
```

Порог покрытия строк и ветвей — 90%. Конфигурация хранится в pyproject.toml.

Все временные данные pytest находятся в .test-tmp. Скрипт проверяет абсолютный
путь, очищает каталог перед запуском и после завершения. Не создавайте соседние
каталоги с суффиксами. Параллельные запуски в одном checkout не поддерживаются.

Изолированные тесты application используют fakes в памяти; SQLite и HTTP
проверяются отдельно. Реальные внешние сервисы для pytest не требуются.

Коммиты оформляются по [правилам проекта](../AGENTS.md):
`[тип]: Описание в прошедшем времени`.
