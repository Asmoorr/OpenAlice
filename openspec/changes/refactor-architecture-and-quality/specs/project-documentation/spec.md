## Purpose

Задаёт компактную точку входа в проект и тематическую документацию, где установка, архитектура, эксплуатация и безопасность поддерживаются без дублирования.

## ADDED Requirements

### Requirement: Краткий README
README SHALL кратко объяснять назначение OpenAlice, показывать схему потока запросов, содержать минимальный quick start, команды проверки и ссылки на подробные документы; подробные пошаговые инструкции MUST находиться в `docs/`.

#### Scenario: Первый запуск новым разработчиком
- **WHEN** разработчик открывает README
- **THEN** он находит требования, минимальные команды запуска, проверку health и ссылки на дальнейшую настройку без чтения полного эксплуатационного руководства

### Requirement: Тематическая структура docs
Документация SHALL разнести как минимум архитектуру, установку и конфигурацию, публикацию навыка и туннеля, уведомления, эксплуатацию и автозапуск, разработку и тестирование, Bruno-сценарии, безопасность и устранение неисправностей по отдельным тематическим страницам.

#### Scenario: Поиск настройки уведомлений
- **WHEN** оператор переходит по ссылке на уведомления из README или индекса docs
- **THEN** он получает полную настройку Home Assistant и Glagol в одном тематическом документе

### Requirement: Единый источник истины
Каждая команда, переменная конфигурации и эксплуатационное правило SHALL иметь одно основное место описания; другие страницы SHALL ссылаться на него вместо копирования расходящихся инструкций.

#### Scenario: Изменение тестовой команды
- **WHEN** штатный entry point тестов меняется
- **THEN** его полное описание обновляется в одном документе, а README содержит краткую ссылку или короткий вызов без дублирования деталей

### Requirement: Проверяемая навигация
Все относительные ссылки внутри README и `docs/` MUST указывать на существующие файлы и корректные заголовки.

#### Scenario: Автоматическая проверка ссылок
- **WHEN** выполняется quality-check документации
- **THEN** отсутствующая локальная страница или некорректная якорная ссылка приводит к ошибке проверки
