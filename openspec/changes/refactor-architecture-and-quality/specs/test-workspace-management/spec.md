## Purpose

Определяет воспроизводимый запуск тестов в Windows без накопления множества временных каталогов в корне проекта и без зависимости от недоступного системного Temp.

## ADDED Requirements

### Requirement: Единственный корень временных данных тестов
Штатный тестовый запуск SHALL использовать только каталог `.test-tmp` в корне проекта для всех данных, создаваемых fixture `tmp_path`, и MUST не создавать каталоги `.test-tmp-*`.

#### Scenario: Последовательные тестовые запуски
- **WHEN** полный набор тестов запускается несколько раз штатной командой
- **THEN** в корне проекта существует не более одного каталога `.test-tmp` и отсутствуют новые `.test-tmp-*`

### Requirement: Безопасная очистка
Штатный тестовый entry point SHALL перед запуском очищать только точно разрешённый путь `.test-tmp` внутри корня проекта, а после успешного запуска SHALL удалять оставшиеся временные данные либо оставлять пустой игнорируемый корень.

#### Scenario: Защита от удаления постороннего пути
- **WHEN** вычисленный путь временного каталога не является дочерним `.test-tmp` текущего проекта
- **THEN** очистка MUST завершиться ошибкой до удаления файлов

#### Scenario: Повтор после прерванного теста
- **WHEN** предыдущий тестовый запуск был прерван и оставил файлы в `.test-tmp`
- **THEN** следующий штатный запуск очищает этот же каталог и не выбирает новое имя

### Requirement: Единая команда проверки
Документация и локальные скрипты SHALL ссылаться на один штатный entry point полного набора тестов, который одинаково настраивает временный каталог и отключает необязательный pytest cache в рабочем дереве.

#### Scenario: Запуск в ограниченном Windows-окружении
- **WHEN** системный временный каталог недоступен, а каталог проекта доступен для записи
- **THEN** штатная команда выполняет тесты, используя `.test-tmp`, без ошибки доступа к системному Temp

### Requirement: Удаление исторического мусора
Миграция SHALL удалить существующие каталоги `.test-tmp-*` из рабочего дерева после проверки, что каждый удаляемый путь находится в корне проекта и соответствует разрешённому шаблону.

#### Scenario: Очистка известных каталогов
- **WHEN** рефакторинг применяется к текущему рабочему дереву
- **THEN** все существующие `.test-tmp-*` удалены, а исходники, данные приложения и пользовательские файлы не затронуты
